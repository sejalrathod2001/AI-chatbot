# 🤖 AI Chatbot

### *An Intelligent AI Chatbot built with Python and Google Gemini*

> *A conversational AI chatbot that generates intelligent, context-aware responses using Google's Gemini model through a simple and interactive web interface.*

---

## 🌟 Overview

**AI Chatbot** is a conversational AI application that enables users to interact with Google's Gemini model through a clean web interface.

The chatbot processes user queries, sends them to the Gemini API, and returns AI-generated responses in real time. It demonstrates API integration, prompt handling, backend development, and AI application development using Python.

---

## 🎯 Problem Statement

Most basic chatbots rely on predefined responses, making conversations repetitive and limited.

This project solves that problem by integrating **Google Gemini AI**, allowing users to have natural, dynamic, and intelligent conversations through an interactive chatbot.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/sejalrathod2001/AI-chatbot.git

cd AI-chatbot
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Add your Gemini API Key

```python
GEMINI_API_KEY="YOUR_API_KEY"
```

Run the application

```bash
python bot.py
```

Open your browser

```
http://127.0.0.1:5000
```
